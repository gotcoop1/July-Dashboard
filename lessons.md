## 2026-08-28: Budget workbooks can disagree with themselves
- **What happened:** `Final_2026_Budget_.xlsx` had three tabs ("Finance Team Summary," "Original Expenses," "Revised Expenses") with very different annual totals per ministry. For example, Care Ministries ranged from $2,200 to $31,300.
- **Lesson:** Never assume a budget file has one set of numbers.
- **Next time:** Ask which tab is authoritative up front, then check it against its own grand total.

## 2026-08-28: Ministry labels don't always match across files
- **What happened:** The tracking workbook and budget file used different names for the same staff-support line.
- **Lesson:** Matching by ratio is a reasonable stopgap, but it's still an assumption.
- **Next time:** Flag every inferred mapping in the report and confirm it with finance before board distribution.

## 2026-08-28: Label gaps instead of filling them
- **What happened:** The source had only high-level YTD totals and no transaction-level detail.
- **Lesson:** Showing "Data Required" kept the dashboard honest and showed what to request next.
- **Next time:** Keep doing this. Never estimate a figure the source doesn't support.
