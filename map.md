## Rules

1. **One topic per file.** If a file starts covering two things, split it.
2. **Name files after what's inside.** Use lowercase with hyphens, such as `fall-budget-review.md`, not `Notes1.md`.
3. **Answer only from the file this map points to, and name that file.** If no file covers the question, say so plainly. Don't guess.
4. **Keep the map current.** When you add a new kind of info or a new folder, add a row above.
5. **Keep it confidential.** Financial, personnel, counseling, giving, volunteer and member details are confidential. Record only what's needed, and never infer or invent sensitive facts.
